# Shengxing Lead Hunter

AI-assisted lead discovery and sales workflow platform for Shengxing / 胜行天下工作室.

## Status

Repository initialized. The first application scaffold is being prepared for development with Codex and the cloud development environment.

## Initial scope

- Lead discovery workspace
- Lead database and pipeline
- Lead scoring
- Public-source research workflow
- Sales follow-up tracking
- AI-assisted lead analysis
- Dashboard and activity tracking

> Important: The system should only use lawful, authorized, and publicly available data sources. It must not bypass platform access controls or collect private personal data without authorization.
